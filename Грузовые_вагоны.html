Грузовые поезда метрополитена

Грузовые поезда – это поезда, которые предназначены для перевозки различных грузов по территории метрополитена. Пример задачи для этого состава – перевезти колёсные пары из одного депо в другое. Данные поезда курсируют вне часа-пик.

Конструкция грузовых вагонов

Такие составы создавались самим метрополитеном. Для этого у вагонов отпиливалась часть крыши. В Москве, например, удаляли примерно треть всей крыши вагона, а в Санкт-Петербурге крышу срезали почти полностью.

Грузовые вагоны создавались путём переоборудования пассажирских вагонов для хозяйственных нужд метрополитена.

Конец эпохи грузовых поездов

Декабрь 2009

Инцидент на станции «Сходненская»

Колёсная пара, перевозимая в вагоне № 3361, продавила дверь и выпала из вагона.

После 2009

Прекращение эксплуатации

Эксплуатация грузовых поездов в Москве прекратилась после этого инцидента. Часть вагонов использовалась для перегонок.

Важно: После инцидента 2009 года эксплуатация грузовых поездов в Московском метро была прекращена из соображений безопасности.

Особенности грузовых вагонов

📦 Назначение

Перевозка колёсных пар, рельсов, запчастей, оборудования между депо

Курсировали вне часа-пик, в ночное время

🔧 Переоборудование

Срез части крыши для погрузки крупногабаритных грузов
